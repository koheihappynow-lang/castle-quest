# キャッスルクエスト（Castle Quest）

4〜7歳向けの英語クイズとお城づくりのゲームです。ブラウザで動きます（iPadのホーム画面に追加して使う想定）。

- 遊んだデータは端末の中（ブラウザ）だけに保存され、外部には送りません。
- 3Dは [three.js](https://threejs.org/)（MIT License）を使っています。
- クイズの写真は Wikipedia の記事の画像（自由なライセンス）を使っています。作者とライセンスはゲーム内の「おうちのひと」→「しゃしんの クレジット」に表示しています。

## PCで動かす

```
node server.js
```

http://localhost:5173 を開きます。
